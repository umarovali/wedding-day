# Свадебное приглашение (React + Vite)

Конверт с сургучной печатью → обложка с цветами → текст приглашения → план дня
(сердечко бежит по линии при прокрутке) → календарь → место → отсчёт → анкета → финал.

## Запуск на компьютере
```
npm install
npm run dev      # открыть http://localhost:5173
npm run build    # готовая папка dist
```

## Что менять
Все данные — в самом верху файла `src/App.jsx`, блок `CONFIG`:
имена, буквы на печати, дата, место, ссылка на карту, план дня, текст анкеты.
Календарь строится сам из `year / month / day`.

## Анкета → Telegram-бот
Ответы гостей (имя и «придёт / не придёт») прилетают вам в Telegram. Токен бота хранится
только на сервере, в код сайта он не попадает.

1. В Telegram напишите **@BotFather** → `/newbot` → получите **токен** (`123456:AA...`).
2. Откройте своего нового бота и нажмите **Start** (иначе он не сможет вам писать).
3. Узнайте свой **chat id**: напишите боту **@userinfobot** — он ответит числом `Id`.
   (Хотите, чтобы ответы шли в общий чат с мужем/женой — создайте группу, добавьте туда бота
   и возьмите id группы, он начинается с `-`.)
4. На Vercel: *Project → Settings → Environment Variables* добавьте две переменные
   `TG_BOT_TOKEN` и `TG_CHAT_ID`, затем сделайте **Redeploy**.
5. Для проверки на своём компьютере скопируйте `.env.example` в `.env` и впишите те же значения
   — тогда `npm run dev` тоже отправляет сообщения.

Файл функции — `api/rsvp.js`. Если переменные не заданы, форма покажет «не получилось отправить».

## Музыка и звук
Звук «волшебного» открытия конверта — `public/magic.mp3` (играет при нажатии на печать, около 5,5 секунды; затем плавно переходит в песню — моменты настраиваются константами `MUSIC_AT` и `MUSIC_FADE` в `src/App.jsx`).
Сейчас в `public/music.mp3` лежит Sting — Shape of My Heart (сжат до 128 кбит/с, ~4 МБ, чтобы быстро грузился на телефонах).
Чтобы сменить трек, положите другой файл в `public/` под именем **`music.mp3`** — он заиграет
после нажатия на печать.
(Используйте трек, на который у вас есть права, например свою запись или лицензированный файл.)

## Публикация на Vercel
Загрузите папку на GitHub и импортируйте репозиторий на vercel.com
(Framework: Vite — определится сам; папка `api` подхватится автоматически).
